NOTES FOR DATASET COLLECTION
==================================================

1. Download PDFs from archive.org sources.
2. Convert PDF to text.
3. Split each book into individual stories.
4. Save raw text files inside the corresponding raw/ folder.
5. Run metadata_extractor.py to generate structured JSON.
6. Validate using dataset_validator.py before committing.

This collection contains enough material to extract approximately:

3000 – 6000 short children's stories.
